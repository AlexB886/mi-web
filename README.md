# Alex Baicu | Web personal

🌐 **Web personal:** https://alexb886.github.io/mi-web/

Portfolio personal desarrollado con HTML, CSS y JavaScript, donde presento mis intereses, proyectos y mi aprendizaje en desarrollo de aplicaciones.

## 🚀 Características

- Diseño web personalizado y adaptable a distintos dispositivos.
- Página principal con modo claro y oscuro.
- Modo videojuego retro con pantalla START, sonido arcade y combate entre un dinosaurio y un león.
- Navegación entre las distintas secciones de la web.
- Secciones personales, proyectos, gustos y contacto.
- Widgets y contenido multimedia.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git y GitHub Pages

## 📂 Estructura del proyecto

- `index.html`: página principal.
- `normal.css` y `normal.js`: estilos y funciones de la web moderna.
- `modo-videojuego.html`: introducción arcade y secuencia de combate.
- `portada.html`: portada del modo videojuego.
- `style.css` y `script.js`: estilos y funciones del modo clásico.
- Otras páginas HTML: secciones personales y páginas legales.

## ▶️ Cómo ejecutar el proyecto

1. Clona o descarga el repositorio.
2. Abre la carpeta del proyecto en Visual Studio Code.
3. Ejecuta `index.html` con Live Server o abre la web publicada en GitHub Pages.
4. Pulsa **Entrar al modo videojuego** para acceder a la experiencia arcade.
