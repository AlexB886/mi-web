Cada proyecto ha sido una forma diferente de aprender: desde crear una tienda online hasta desarrollar mi propia web utilizando HTML, CSS, JavaScript e inteligencia artificial.

01
E-COMMERCE · SHOPIFY

Dermalux

Exploración
EL RETO

Cuando empecé a crear mi primera página con Shopify, me encontré con muchas configuraciones que todavía no dominaba: e-commerce, elección del nicho y diseño. No sabía programar, pero tenía clara una cosa: quería sacarle el máximo rendimiento posible a la página.

QUÉ HICE

Empecé formándome por mi cuenta con tutoriales de YouTube y cursos gratuitos. Después pasé a la práctica, explorando los menús y configuraciones de Shopify. Creé una marca llamada Dermalux, elegí como nicho una crema para la piel y empecé a plantear la estructura de la tienda y su identidad.

HERRAMIENTAS
Shopify AutoDS Shopify Collective Shopify Magic Sidekick
RESULTADO / APRENDIZAJE

El proyecto no llegó a completarse. En ese momento estaba en 1.º de Bachillerato y lo estaba desarrollando como hobby, por lo que llegó a menos del 15% de su desarrollo.

Aun así, aprendí mucho sobre cómo se estructura una tienda online, cómo cuidar su diseño, cómo funciona el e-commerce, cómo plantear campañas de publicidad y conceptos relacionados con stock y dropshipping.

"No terminé la tienda, pero aprendí mucho más de lo que esperaba."
02
WEB · IA · HTML · CSS · JS

Mi web personal

En desarrollo
EL RETO

Con esta web personal quiero aprender más sobre el mundo de la programación aprovechando también una herramienta que está cobrando cada vez más importancia: la inteligencia artificial.

Mi objetivo es crear una página que reúna información sobre mí, mis proyectos, mis intereses y mi evolución, cuidando tanto el funcionamiento como cada detalle visual.

QUÉ HICE

La página empezó a cobrar vida a partir del commit 16, cuando ya tenía una estética mucho más definida. Desde entonces he seguido desarrollándola y escalándola mediante diferentes iteraciones.

Durante el proceso he trabajado con HTML, CSS y JavaScript, utilizando la IA local del centro como apoyo para generar, modificar y mejorar el código.

HERRAMIENTAS
HTML CSS JavaScript IA local GitHub
HTML · CSS · JavaScript
IA · Aprendizaje · Desarrollo
RESULTADO / APRENDIZAJE

El proyecto continúa en desarrollo y ha evolucionado considerablemente desde sus primeras versiones. Actualmente reúne diferentes páginas, navegación, formulario de contacto, modo claro/oscuro, diseño responsive y elementos interactivos.

Este proyecto me ha enseñado que, al crear una página web, muchas veces el límite está en lo que eres capaz de imaginar y desarrollar.

"La gracia está en seguir pensando qué se puede crear."

02 — Evolución

Todavía estoy construyendo.

No considero estos proyectos como trabajos terminados, sino como puntos de partida que me han permitido aprender, probar nuevas herramientas y seguir desarrollando ideas.
