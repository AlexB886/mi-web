Política de cookies

Información sobre las cookies y tecnologías similares utilizadas en este sitio web.

1. ¿Qué son las cookies?

Las cookies son pequeños archivos que pueden almacenarse en el dispositivo del usuario cuando visita un sitio web.

Estas tecnologías permiten recordar determinadas preferencias y facilitar el funcionamiento de algunas características del sitio web.

2. ¿Qué cookies utiliza este sitio web?

Este sitio web utiliza principalmente mecanismos de almacenamiento local del navegador para recordar determinadas preferencias del usuario.

En concreto, se utiliza el almacenamiento local (localStorage) para recordar la elección realizada por el usuario respecto al aviso de cookies.

La preferencia se guarda mediante la clave:

alexbaicu_cookie_consent

3. Finalidad

La finalidad principal de este almacenamiento es recordar si el usuario ha aceptado o rechazado las preferencias relacionadas con el aviso de cookies.

De esta forma, el aviso no tiene que mostrarse continuamente después de que el usuario haya realizado una elección.

4. Tipos de almacenamiento

En el funcionamiento actual del sitio web se utiliza principalmente:

  • Almacenamiento necesario: utilizado para recordar determinadas preferencias necesarias para el funcionamiento de la web.
  • Preferencias: permite recordar determinadas opciones seleccionadas por el usuario, como el modo claro u oscuro.

5. Modo claro y modo oscuro

El sitio web permite seleccionar entre modo claro y modo oscuro.

Esta preferencia se almacena en el navegador mediante localStorage para mantener la selección del usuario cuando vuelve a visitar la página.

6. Cookies de terceros

Algunas funcionalidades integradas en el sitio web pueden proceder de servicios externos.

Entre ellos pueden encontrarse servicios como Spotify, Web3Forms, GitHub o contenidos externos integrados mediante terceros.

Estos servicios pueden utilizar sus propias tecnologías de almacenamiento o cookies conforme a sus respectivas políticas.

7. Gestión de las cookies

El usuario puede gestionar las preferencias relacionadas con las cookies mediante el aviso mostrado al acceder al sitio web.

También puede utilizar la opción Configurar cookies disponible en el pie de página.

8. Configuración del navegador

El usuario puede configurar su navegador para bloquear, eliminar o limitar el almacenamiento de cookies y otras tecnologías similares.

La forma de realizar esta configuración depende del navegador utilizado.

9. Consecuencias de desactivar las cookies

La desactivación o eliminación de determinados elementos de almacenamiento puede provocar que algunas preferencias no se recuerden correctamente.

Las funciones básicas del sitio web pueden seguir estando disponibles, aunque algunas características podrían no funcionar exactamente como se espera.

10. Actualización de esta política

Esta política de cookies puede modificarse cuando cambien las funcionalidades del sitio web, los servicios utilizados o la normativa aplicable.

Se recomienda consultar periódicamente esta página para conocer cualquier actualización.
